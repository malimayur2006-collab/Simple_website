 🚀 Placement Preparation Portal

> 🎯 **Your All-in-One Platform for Jobs, Coding Practice, and Interview Preparation**

A modern, interactive, and responsive web application designed to help students prepare for campus placements, improve technical skills, practice Data Structures and Algorithms (DSA), and explore job opportunities.

---

 ✨ Key Features

💼 1. Job Portal
- 🔍 Real-time job search and filtering.
- 📋 Detailed job descriptions and eligibility criteria.
- 📝 Quick and easy job application forms.
- 🏢 Recruiter job posting functionality.
- 📊 Track and manage job applications.

 🧠 2. Interview Preparation Hub
- 💻 Technical interview questions and answers.
- 🔢 Aptitude and logical reasoning practice.
- 👥 HR interview questions and sample answers.
- ⏱️ Interactive timed quizzes.
- 📈 Automatic score calculation and performance tracking.
- 🎯 Real interview questions and candidate preparation strategies.

⚡ 3. Dedicated DSA Topic-Wise Sheet

Practice essential coding interview topics through a structured, topic-wise problem sheet.

📚 12 Core DSA Topics**

1. 📦 Arrays
2. 👉 Two Pointers & Sliding Window
3. 🔤 Strings
4. 🔗 Linked Lists
5. 📚 Stacks & Queues
6. 🔎 Binary Search
7. 🌳 Trees & Binary Search Trees
8. 🕸️ Graphs — BFS, DFS & Kahn's Algorithm
9. 🧩 Dynamic Programming — 1D, 2D, Coin Change & LIS
10. ⚙️ Greedy Algorithms & Bit Manipulation
11. 🔄 Recursion & Backtracking
12. 🏔️ Heaps & Priority Queues

🔥 Smart DSA Tracking Features**
- 📊 Live progress bar with percentage calculation.
- ☑️ Mark problems as solved or unsolved.
- ⭐ Bookmark challenging questions for revision.
- 📝 Add personal notes and corner-case reminders.
- 💡 Understand the optimal approach and problem-solving intuition.
- ⏱️ View time and space complexity.
- 💻 Switch between Python, C++, and Java solutions.
- 📋 Copy code with one click.
- 🔄 Track learning progress through interactive updates.

 🏢 4. Company Preparation Directory
- 🏭 Explore company-specific recruitment information.
- 📋 Review hiring patterns and exam syllabi.
- 🧪 Understand assessment rounds and selection processes.
- 🎯 Prepare with company-focused practice materials.

📊 5. Personal Career Dashboard
- 📈 Monitor placement preparation progress.
- 💼 Track job applications.
- ⚡ View DSA completion statistics.
- 🧠 Review quiz attempts and scores.
- 🎯 Organize your preparation journey in one place.

 🎨 6. Modern User Interface
- 📱 Responsive design for desktop, tablet, and mobile.
- ✨ Modern glassmorphism effects and animations.
- 🔔 Interactive toast notifications.
- 🔎 Global search with `Ctrl + K`.
- 🧭 Responsive navigation and mobile menu.
- 🌐 Simple and user-friendly experience.

 ⚙️ Installation & Setup

📌 Prerequisites

Ensure the following are installed on your computer:

- Python 3.10 or later
- Pip package manager
- A modern web browser
- Git (optional)

 🚀 Step 1: Open the Project Directory

Open PowerShell or Command Prompt and navigate to your project folder.

```powershell
cd "C:\Users\dell\OneDrive\Desktop\First project"
```

 📦 Step 2: Install Dependencies

```powershell
python -m pip install -r requirements.txt
```

 ▶️ Step 3: Run the Application

```powershell
python app.py
```

 🌐 Step 4: Open the Website

Open your browser and visit:

https://simple-website-gamma-ashy.vercel.app

🎉 Your Placement Preparation Portal should now be running locally.

> 💡 **Note:** The SQLite database is initialized automatically on the first run if your application implements database initialization and seed-data loading. Confirm this behavior in `app.py` before relying on automatic setup.
